# Sri Sri Academy

Production-ready Next.js 15 App Router project for a premium international school website.

## Stack

- Next.js 15
- TypeScript
- Tailwind CSS v4
- Framer Motion, GSAP ScrollTrigger, Lenis
- shadcn/ui-style primitives
- Embla Carousel, Swiper, React CountUp

## Commands

```bash
npm install
npm run dev
npm run build
```
